## Omg Hey 🌸

I'm [Kavish](https://kabbagepatch.github.io/#/). Nice of you to visit my page 🌱

I've worked in software for over 10 years now and have touched a lot of different areas, probably too many of them, from full-stack applications to platform tooling to games. Between it all, I love to continue learning and growing as a software developer while still having fun with it

Current obsessions include Tauri 🌻, Vue 🌵 and Godot 🎮 \
I like making small apps that do one thing I can use in my day-to-day. Like this focus timer I made. Or an app to help my partner be more intentional about computer use. A Spotify data explorer to get more insight into my listening history. And even a Pokemon assistant to help skip the type charts and constant lookups while I was playing Legends ZA. All of these were made in Tauri with vanilla JS or Vue.
